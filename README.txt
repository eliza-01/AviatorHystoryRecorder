Исправление блока «Сопоставление» и шкалы графика.

Сопоставление теперь показывает два значения рядом:
  отрицательные | положительные × (x − 1)

Также шкала Y использует округлённые «красивые» деления вместо случайных дробей,
возникавших из-за автоматического padding и равномерного деления диапазона.

Применение:
  docker compose up -d --build api
