Исправление веб-интерфейса графика

Изменения:
- надпись «В базе пока нет результатов» скрывается при наличии данных;
- поле «Вмещать на графике» задаёт количество результатов, видимых по горизонтали;
- поле «Высота графика» задаёт количество пунктов баланса, видимых по вертикали;
- остальные данные доступны горизонтальной и вертикальной прокруткой;
- API анализа возвращает все результаты без прореживания точек;
- при первом открытии график показывает последние результаты;
- автообновление сохраняет положение прокрутки, если пользователь просматривает историю.

Установка:
1. Распаковать архив в корень проекта с заменой файлов.
2. Выполнить:
   docker compose up -d --build api
3. Обновить страницу с очисткой кэша: Ctrl+F5.

Расширение Chrome менять не требуется.
Fakebet (v1.10.1): при включённой активной стратегии имитирует активность только вне реального цикла ставок. После нового результата, если до сигнала остаётся минимум 2 результата и до активного автообновления не меньше 10 секунд (либо оно выключено/приостановлено стратегией), нажимает «Ставка» и через 300 мс подтверждённо отменяет её. На странице показывается отдельный бадж Fakebet.
