- Выигрыш: множитель строго больше целевого.
- Проигрыш: множитель меньше или равен целевому.
- После достижения требуемой серии проигрышей вход выполняется со следующего результата.
- Пока цикл ставок активен, новые сигналы входа игнорируются.
- После выигрыша или стопа счётчик ожидания начинается заново.

### Расчёт ставки внутри цикла

Цель каждого цикла — вернуть все накопленные потери и получить чистую прибыль, равную начальной ставке цикла.

```text
следующая ставка = max(
    начальная ставка цикла,
    ceil_0.01((накопленные потери + целевая прибыль) / (множитель - 1))
)
```

### Реинвестирование

```text
минимальный депозит = ceil(сумма полной прогрессии до стопа)
шаг реинвестирования = минимальный депозит / 20
начальная ставка цикла = 0,20
    + floor(max(текущий депозит - минимальный депозит, 0)
            / шаг реинвестирования) × 0,01
```

Начальная ставка фиксируется на весь активный цикл и пересчитывается только перед следующим входом.

## Формат CSV

| Колонка | Значение |
|---|---|
| `id входа` | ID первого результата, на котором начала играть ставка |
| `id` | ID результата, завершившего цикл выигрышем или стопом |
| `начальная ставка` | Базовая ставка, зафиксированная на весь цикл |
| `депозит после цикла` | Депозит после завершения данного цикла |
| `Время` | Время завершения в формате `число HH:MM` |
| `порядковый номер шага` | Номер результата внутри активного цикла |
| `результат` | `выигрыш` или `стоп` |
