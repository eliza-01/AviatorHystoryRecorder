Aviator History Recorder — версия 1.5.3

Установка распакованного расширения:
1. Откройте chrome://extensions
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку extension.

После обновления файлов:
1. Нажмите «Обновить» у расширения на странице chrome://extensions.
2. Полностью перезагрузите вкладку с Aviator.

Раздел «Подготовка»:
- включает автоматическую настройку первого блока ставки после загрузки игры;
- переключает вкладку «Ставка» на «Авто»;
- включает «Авто кешаут»;
- устанавливает кэшаут и размер ставки;
- не нажимает кнопку ставки и не включает автоставку.

Значения вводятся как пользовательский ввод: поле активируется, текст заменяется
через input-события, затем фокус переносится за пределы поля. Это запускает
blur-обработчик app-spinner, который записывает значение в модель Angular, а не только
визуально меняет текст внутри input.

В версии 1.5.3 удалены широкие резервные селекторы и дублирующая генерация событий
из первых вариантов «Подготовки». Оставлены точные селекторы текущего интерфейса
Aviator и рабочая последовательность ввода с обязательной потерей фокуса.

Автообновление в popup отображается одной компактной строкой:
«Автообновление — Каждые [секунды] сек — тумблер».

Важно: после обновления расширения вкладку Aviator нужно перезагрузить полностью,
иначе в уже открытом iframe останется старая версия content script.
