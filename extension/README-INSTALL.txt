Aviator History Recorder — версия 1.9.1

Установка распакованного расширения:
1. Откройте chrome://extensions
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку extension.

После обновления файлов:
1. Нажмите «Обновить» у расширения на странице chrome://extensions.
2. Полностью перезагрузите вкладку с Aviator.

Раздел «Подготовка»:
- включает автоматическую настройку первого блока ставки после загрузки игры;
- переключает вкладку «Ставка» на «Авто»;
- включает «Авто кешаут»;
- устанавливает кэшаут и размер ставки;
- не нажимает кнопку ставки и не включает автоставку.


Telegram-уведомления:
- токен бота хранится только в .env backend-сервиса;
- в popup расширения пользователь указывает свой Telegram ID;
- бот уведомляет о выбранной длине серии <= 3.40, прибыли и достижении стопа;
- для прибыли и стопа указываются шаг завершения и просадка;
- перед использованием пользователь должен открыть диалог с ботом и нажать Start.

Раздел «Стратегии»:
- содержит стратегию «10+ - x3.40»;
- ждёт 10 последовательных результатов <= 3.40;
- после сигнала ставит со следующего раунда;
- без реинвестирования начинает с 0.20; после проигрыша повышает ставку с шагом 0.01 для возврата минуса и прибыли не меньше стартовой ставки текущего цикла;
- на чистой установке выбирает стоп 12; позволяет изменить его на шаги 1–100 или работать без стопа;
- для каждого шага стопа показывает размер ставки и общий потенциальный минус после её проигрыша;
- перед каждой ставкой проверяет вкладку «Авто», авто кешаут 3.40 и размер ставки;
- физически нажимает штатную кнопку «Ставка» тем же способом, что используется в «Подготовке»;
- при 8/10 приостанавливает автообновление и заранее готовит интерфейс: вкладка «Авто», авто кешаут 3.40 и актуальная стартовая ставка следующего цикла;
- при 10/10 повторно проверяет интерфейс и только затем нажимает кнопку ставки;
- тумблер «Реинвестирование» рассчитывает минимальный виртуальный депозит как сумму ставок до выбранного стопа включительно и округляет его вверх до целого; шаг реинвестирования равен минимальному депозиту / 20, за каждый полный шаг к стартовой ставке нового цикла добавляется 0.01;
- реинвестирование недоступно при режиме «Без стопа», потому что конечный минимальный депозит в этом режиме определить нельзя;
- стартовая ставка и целевая прибыль фиксируются на весь начавшийся цикл; после прибыли или стопа виртуальный баланс обновляется;
- использует только один основной игровой iframe; копии истории и остальные iframe не могут менять состояние или ставить;
- не запускает ставки ретроспективно, если при первом подключении серия уже достигла 10/10: такая серия пропускается до сброса.

«Подготовка» автоматически выключается и блокируется, пока активна стратегия.

Важно: после обновления расширения вкладку Aviator нужно перезагрузить полностью,
иначе в уже открытом iframe останется старая версия content script.
