Aviator History Recorder 1.3.0

ВАЖНО: это готовая папка расширения, а не патч поверх старой.

Установка:
1. Распакуйте архив в новую отдельную папку.
2. Откройте chrome://extensions.
3. Удалите старый Aviator History Recorder либо выключите его.
4. Включите "Режим разработчика".
5. Нажмите "Загрузить распакованное расширение".
6. Выберите папку, внутри которой сразу лежит manifest.json.
7. Полностью закройте вкладку игры и откройте её заново.

В popup должна отображаться версия v1.3.0.
DOM-сборщик должен показать:
- Кадров расширения: больше 0
- Блок истории: найден
- Результатов в блоке: примерно 20-30

Сбор выполняется опросом DOM каждые 400 мс. Отслеживается любой подходящий
.payouts-block с прямыми дочерними .payout. Динамические Angular-атрибуты
_ngcontent-* не используются.
